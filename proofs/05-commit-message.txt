docs(cicero-core): remove nonexistent parse() reference from class JSDoc

The class JSDoc on Clause, Contract, and TemplateInstance told readers to set template data by either calling setData or by calling a parse method that accepts natural language text. TemplateInstance exposes no such parse method and neither does Clause or Contract, so the sentence has misled users since the Cicero TypeScript port dropped the legacy parser.

This change removes the stale `or by calling the parse method ...` clause in all three files and keeps the setData sentence, following Option 2 from issue #881. It also fixes contract.ts, which mis-labels its own subject as `A Clause must be constructed ...`; the sentence now correctly starts with `A Contract must be constructed ...`.

No runtime behaviour changes; this is a documentation-only fix.

Credit: issue #881 was reported by @Divyansh2992, who also soft-claimed the work at the time without a follow-up PR; this PR adopts Option 2 as proposed on the issue.
